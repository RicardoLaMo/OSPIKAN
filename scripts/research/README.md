# Research Scripts

This directory holds exploratory and narrative-driven scripts that are useful for experiments, demos, and one-off investigations, but are not primary operator entry points for the repo.

Keep stable user-facing commands in `scripts/` at the top level.
Move ad hoc exploration, validation experiments, and notebook-integration helpers here.

Current examples include:
- narrative-to-manifold demos
- prior-tension and regime-shift challenge scripts
- notebook-integration helpers
