# Scripts

This directory is organized into three buckets:

- `scripts/options/`
  - Options DSL, REPL, KAN training, and QA tooling.
- `scripts/silver/`
  - Stable silver-pipeline runners, reports, validation, and training utilities.
- `scripts/research/`
  - Exploratory and one-off investigation scripts.

Top-level `scripts/*.py` and `scripts/*.sh` paths are compatibility wrappers so existing commands and documentation continue to work.
